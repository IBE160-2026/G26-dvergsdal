# Accessibility review 2

Second pass, focused on what changed since the 2026-11-11 review. Findings from that review that [review-resolution.md](review-resolution.md) marks as fixed are not repeated, and none of them has regressed in the spines. Findings are about what the spines specify or fail to specify. The renders are used as evidence only.

## Summary

| Severity | Count |
|---|---|
| Critical | 0 |
| High | 3 |
| Medium | 4 |
| Low | 10 |
| **Total** | **17** |

**Verdict.** The new pages are semantically well specified: the timeline is an `ol` in time order, chapter lines are `h2`, icons are decorative, status tags carry an icon and a word, and the dialogs have roles and initial focus. Three gaps need fixing before build:

- **Reflow at 200 % zoom has regressed for the new components.** The programme timeline, the front-page topic rows and every fixed-width image overflow at the 180 CSS px check width that the spines themselves require.
- **Dialog focus after confirming is wrong.** The spine sends focus back to a trigger that no longer exists after the action.
- **The spines contradict themselves on admin text contrast and on jump-link target size.** These are smaller, but they break the spines' own rules.

### How this was checked

- I read both spines in full and cross-checked each finding against the spine text (section names are given in the table).
- I rendered the approved mockups in headless Chrome inside 180px and 320px iframes, so the pages' own media queries apply. The renders use 16px gutters where the spine asks for 8px below 260px, so every overflow claim below is also recomputed from the spine's tokens.
- I did not re-measure contrast; the values in DESIGN › Contrast pairs are taken as stated.

## What holds up

- **Programmet.** The `ol` in time order, `<time>` elements, decorative icons, and alternation in CSS only, so reading and Tab order follow time.
- **Vår historie.** Chapters as `h2` under the page `h1`, the signature as text, and a short photo alt.
- **Praktisk informasjon.** Jump links in a `nav` labelled «Hopp til», with `scroll-margin-top` tied to the bar height.
- **Status tags.** Text first, with distinct icon shapes, in A4 and A9. «Endret» uses the info shape.
- **Tier-3 dialog.** It does not depend on case, has phone-keyboard attributes, keeps the button enabled with an inline error, and places the destructive button apart.
- **Tier-2 and consent dialogs.** Focus starts on «Avbryt».
- **Helper line.** 20px cream with a rule, so it is not colour alone. Action buttons are hidden, not greyed.
- **G1.** One `h1`, no personal data, and a fix-it sentence.
- **G12.** Five parts in plain bokmål, with withdrawal per person by name.
- **Form, check page and receipt.** The redrawn screens keep the earlier fixes: the error summary first and focused, the field error inside the fieldset, «Endre» with hidden context, the polite running total, and «Kopier» buttons with their own names.
