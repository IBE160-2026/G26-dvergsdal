{% comment %} Notice (Story 1.4a, UX-DR17, NFR-5). Use on a cream surface: {% include "wedding/components/notice.html" with variant="warning" text="Svaret er ikke sendt ennå." only %} Always end the include with `only`, so a `live` or `variant` in the page's own context never leaks in (a notice at load must not become a live region). variant: "success", "warning", "error" or "info"; anything else renders as info. live: only for a notice added after the page has loaded. It then becomes a live region: role="alert" for errors, role="status" for the others. A notice present at page load is never a live region. focus: only for a notice the page opens with focus on, such as the RSVP form's error after a failed CSRF check (Story 2.1, UX-DR52): it gets tabindex="-1" and autofocus, so no script is needed. items: optional list of lines shown under the text (Story 4.2, FR-38: what differs in a conflict notice), as a `
    `; after: optional paragraph under the list. Neither makes the notice live. Error and warning text get the prefix «Feil:» / «Obs:», and each variant has its own icon shape, so the state never depends on colour alone. The notice never hides itself. {% endcomment %}
